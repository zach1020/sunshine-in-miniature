# Capturing the presets

The initial release contains shader code and documentation. A screenshot gallery can be added separately.

For a useful comparison:

1. Choose a well-lit scene with a foreground, a clear subject near the center, and background scenery.
2. Capture **Clear**, **Diorama**, and **Diorama Max** with the same camera position and render resolution. Pause the game between captures if practical.
3. Capture the **rendered game window** with the operating system's screenshot tool. In the tested Dolphin 2609a setup, Dolphin's built-in screenshot output omitted the post-processing effect.
4. Keep the game image unobstructed by menus, notifications, desktop content, or the mouse cursor.
5. Note the preset, any changed sliders, Dolphin version, backend, internal resolution, and whether Max's Crisp mode was enabled.

Do not use screenshots of the separate ray-traced mesh prototype to advertise these shaders: that prototype's sprites, geometry renderer, and lighting are not part of this package. Do not retouch the effect or present a generated mockup as an in-game capture.

Suggested names for a future gallery: `screenshots/clear.png`, `screenshots/diorama.png`, and `screenshots/diorama-max.png`. Game imagery remains the property of its respective rights holders.
